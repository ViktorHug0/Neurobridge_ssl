**F1–F6: zero of30 complete; no epoch checkpoint saved.** The only run files are
F1/sub01's manifest/lock and F2/sub01's lock. Local worker513 failed with CUDA OOM
while another process held9GB. Its shell dependency waited only for the existence
of `summary.json`, which appears after the first completed reference fold, rather
than the completion of the reference worker. Worker515 (job53187) failed during
construction because `atm.enc_eeg.tsconv` is not a valid module path; the patch
embedding is nested at `atm.enc_eeg[0]`.

There is also a scientific mismatch: `full_sharing.py` replaced the approved
F3–F6 attention-after-stem/compute-once designs with different weight-tying arms.
Consequently fixing only the construction error would not run the agreed study.
Other setup differences needing correction include normalizing raw image inputs
before their learned projectors (the standalone references use raw features),
forcing subject token10 in validation/test, and incompatible native flatten
orders for direct readout tying. Its EEG parameter accounting double-counts
shared parameters across the two encoders. The launch had no demonstrated
full-model training preflight.

At inspection no training jobs remained beyond interactive allocation52739;
both GPU queues had exited. No model/trainer fixes or new launches were made
during this results audit. The next sharing launch needs the agreed configuration
definitions restored, matched input/evaluation conventions, genuine dependency
checks and real-data GPU/resume verification.
